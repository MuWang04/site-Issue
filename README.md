# site-Issue

MuWang 个人网站的问题反馈与功能建议仓库。

本仓库专门接收以下站点的问题反馈和功能建议：

- 网站打不开或访问异常
- 页面样式、显示或响应式问题
- 功能异常或交互故障
- 性能卡顿或加载缓慢
- 新功能建议或内容建议

本仓库只处理网站相关问题，不用于闲聊或与本站无关的反馈。

## 提交 Issue

请从 [新建 Issue](https://github.com/MuWang04/site-Issue/issues/new/choose) 开始，并选择最符合情况的表单：

| 表单 | 适用场景 |
| --- | --- |
| [问题反馈](https://github.com/MuWang04/site-Issue/issues/new?template=bug_report.yml) | 已经发生的功能、页面、显示、性能或访问问题 |
| [功能建议](https://github.com/MuWang04/site-Issue/issues/new?template=feature_request.yml) | 希望网站新增某项功能、页面或内容 |
| 紧急问题或不便公开的内容，可以发邮件 | 发送邮件 mailto:muwang@046699.xyz |

普通用户不能直接创建空白 Issue，必须先填写表单。

## 域名范围

提交的问题或建议必须与以下域名之一有关：

- `www.046699.xyz`（主站）
- `3d.046699.xyz`（3D 子站）
- `*.046699.xyz`（其他子域）

表单会要求你先确认问题属于上述域名范围。与其他域名无关的问题，请不要提交到这里。

## 如何描述问题

问题反馈至少应包含：

1. 发生了什么
2. 如何复现（按顺序列出操作步骤）
3. 你期望出现什么结果
4. 使用的页面、设备和浏览器环境
5. 必要时附上截图

表单中已包含以下字段，请尽量填写：

- **问题涉及页面**：主站 / 3D 子站 / 其他
- **所在省份/地区**：帮助判断是否是地域网络问题
- **问题类型**：网站打不开 / 功能异常 / 显示样式 / 性能卡顿 / 其他
- **使用的设备**：桌面端（Windows/macOS/Linux）或移动端（安卓/苹果/鸿蒙/纯血鸿蒙）
- **浏览器版本**（可选）：浏览器名称和版本，例如 `Microsoft Edge 版本 151.0.4129.107`

## 隐私与安全

这是公开仓库。请不要在 Issue、评论或截图中提交：

- 手机号、邮箱、真实姓名、地址等不必要的个人信息
- 未脱敏的请求头、响应体或日志


## Issue 处理

维护者会根据内容添加 Label，并可能要求补充信息或合并重复 Issue。与网站无关、信息不足或重复的 Issue，可能会被关闭。

Issue 用于网站反馈，不是实时客服渠道，因此不保证即时回复，但每一条都会认真看。
